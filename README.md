# Monocode E-Commerce

A full-stack e-commerce website built with the **PERN** stack. The project is currently in its initial development stage


## 🎯 Project Goals

**Monocode E-Commerce** is being built as a complete full-stack e-commerce application rather than a simple storefront.

The goal is to implement the complete flow from browsing products to checkout, payment, order creation, and order management.

The application will support both **customers** and **administrators**, with role-based access control separating their permissions and functionality.


## Tech Stack

- Express
- TypeScript

- Stripe
